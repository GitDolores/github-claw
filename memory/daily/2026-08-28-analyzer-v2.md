## 关键修复（调试中发现）

- 正则里 `ws://` 未转义导致语法错误
- 大文件采样只取头 20KB，CLI/main 逻辑在文件尾部被漏掉 → 头 20KB + 尾 10KB
- transformers 的 pyproject.toml 无 deps（tool 配置），依赖在 setup.py 的 `deps["name"]` 风格里 → 空结果回退 setup.py
- `benchmark/requirements.txt` 子目录文件劫持 manifest 匹配 → 限定根目录
- 本地克隆需 CLONE_PROXY 环境变量走代理（CI 无此问题）
